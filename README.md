# Xuideck Fantasy

Weekly fantasy sports for any public X account.

Draft five. Play your league. Likes are runs. A 100k post is a home run.

Live: https://fantasy.xuideck.com

## Play

1. Open Matchup
2. Add any handle on Players
3. Create a league and share the 6-letter code

## Deploy

Vercel. Set `VITE_PUBLIC_HOSTNAME=fantasy.xuideck.com`. Firebase + Convex are optional for cross-device leagues.
